Notre studio de jeux mobiles

Conte Games Studio est un studio indépendant de jeux mobiles, né à Saint-Chamond (Loire, France). Il a été fondé par Anthony Conte, qui imagine, dessine et publie ses jeux avec une même idée : des jeux gratuits, accessibles et faits pour être partagés en famille.

Le site du studio existe en 130 langues, pour que chaque joueur retrouve les jeux dans sa langue.

Nos jeux gratuits

  • COCOBOUM! : Jeu de bulles gratuit
  • Les Tableaux Ensorcelés : Jeu de puzzle gratuit, sans pub
  • Royaume des Mots Croisés : Jeu de mots croisés gratuit
  • Mieux Chaque Jour : Application yoga, nutrition et bien-être
  • Caligula vs Gladiators : Combats de gladiateurs dans l’arène
  • Sauve qui Flèche ! : Casse-tête de flèches médiéval
  • Royaume des Énigmes : Jeu d’énigmes et de combinaisons

Questions fréquentes

Les jeux de Conte Games Studio sont-ils gratuits ?

Oui, les jeux du studio se téléchargent gratuitement. Le détail de chaque jeu est sur sa page.

Où télécharger les jeux ?

Sur l’App Store pour iPhone et, pour certains jeux, sur Google Play pour Android. Chaque page de jeu donne les boutons officiels quand le jeu est disponible.

Qui est derrière le studio ?

Anthony Conte, entrepreneur individuel installé à Saint-Chamond, en France.

Comment contacter le studio ?

Par e-mail à contegamesstudio@gmail.com.
